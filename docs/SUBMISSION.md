# GenLayer Project Explorer submission

**Contribution type** Builder · Projects

**Project name** AccessRoute

**Suggested tags** Oracles or Real-World Data for the primary tag, with Public Infrastructure and Accessibility if available.

**One-liner** Check step-free transit routes against elevator evidence and compare entrances with finalized, per-leg GenLayer verdicts.

**Overview**

AccessRoute checks proposed step-free station paths at the time each leg will use its elevators. GenLayer validators independently fetch evidence and compare canonical per-leg verdicts, affected lift IDs and time windows. The finalized Harbor Exchange demo shows a north entrance blocked by maintenance and a supported south entrance through the same platform transfer. A second mode checks the official NYC Subway MTA outage feed for reported closures on user-supplied elevator IDs. Missing outage data yields insufficient evidence. The public app prepares Studio built-in account transactions, tracks finality and displays evidence-backed records.
